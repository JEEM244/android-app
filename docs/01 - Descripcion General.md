# Descripcion General

> <- Volver a [[INICIO]]

## Que es esta app?

Esta aplicacion de Android fue desarrollada en **Kotlin** como proyecto academico. El objetivo fue aprender la arquitectura de una aplicacion movil: como se crean pantallas, como se navega entre ellas y como se usan los componentes visuales.

## Cuantas pantallas tiene?

La app tiene **4 pantallas** que se acceden desde un menu principal:

| Pantalla | Boton en el menu | Funcion |
|---|---|---|
| [[Pantalla - MainActivity\|MainActivity]] | — | Menu de navegacion |
| [[Pantalla - QuizActivity\|QuizActivity]] | **PIA** | Cuestionario de 12 preguntas |
| [[Pantalla - ColorActivity\|ColorActivity]] | **Etapa 4 Evidencia** | Cambia el color de fondo |
| [[Pantalla - CalculadoraActivity\|CalculadoraActivity]] | **Etapa 4 Dimension 3** | Calculadora basica |
